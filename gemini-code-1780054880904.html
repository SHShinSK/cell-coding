Cell Coding: Phase 1

TypeScript 및 RxJS를 활용한 독립 세포 간 비동기 신호 처리 시뮬레이션

01_ARCHITECTURE_SUMMARY

Signal (신호)

세포 간의 유일한 매개체입니다. 읽기 전용(Immutable) 상태로 신경계에 방출되며, 수신 대상을 특정하지 않습니다.

Nervous System (신경계)

RxJS Subject를 기반으로 구축된 중앙 이벤트 버스입니다. 세포가 방출한 신호를 가로채어 적절한 세포의 막으로 라우팅합니다.

Membrane (막)

TS Decorator로 구현됩니다. 세포가 어떤 신호를 받아들일지(accepts) 선언적으로 정의하며, 필터링을 수행합니다.

02_CORE_IMPLEMENTATION (index.ts)

TypeScript src/index.ts 
import { Subject } from 'rxjs';
import { filter } from 'rxjs/operators';

// ── 1. 신호 (Signal) ────────────────────────────────────────
interface Signal {
  type: string;
  payload: any;
  timestamp: number;
}

const createSignal = (type: string, payload: any = {}): Signal => ({
  type, payload, timestamp: Date.now(),
});

// ── 2. 신경계 (Nervous System) ──────────────────────────────────
class NervousSystem {
  private bus = new Subject<Signal>();

  emit(signal: Signal) {
    this.bus.next(signal);
  }

  observe(signalType: string) {
    return this.bus.pipe(filter((signal) => signal.type === signalType));
  }
}
const appNervousSystem = new NervousSystem();

// ── 3. 세포 기반 클래스 및 막(Membrane) ─────────────────────────
abstract class BaseCell {
  protected emit(signal: Signal) {
    appNervousSystem.emit(signal);
  }
}

function membrane(accepts: string) {
  return function (target: any, propertyKey: string, descriptor: PropertyDescriptor) {
    const originalMethod = descriptor.value;
    setTimeout(() => {
      appNervousSystem.observe(accepts).subscribe((signal) => {
        originalMethod.apply(target, [signal]);
      });
    }, 0);
  };
}

// ── 4. 구체 세포 (카메라 & 알람) ────────────────────────────────
class CameraCell extends BaseCell {
  role = "외부 환경의 움직임을 감지하여 신호 발생";

  detectMotion(x: number, y: number) {
    this.emit(createSignal('MotionDetected', { x, y, confidence: 0.98 }));
  }
}

class AlarmCell extends BaseCell {
  role = "움직임 감지 신호를 받아 사이렌 작동 신호 발생";

  @membrane('MotionDetected')
  onMotion(signal: Signal) {
    if (signal.payload.confidence > 0.9) {
      this.emit(createSignal('SirenActivated', { volume: 100, pattern: 'beep-beep' }));
    }
  }
}

// ── 5. 시뮬레이션 ─────────────────────────────────────────────
const camera = new CameraCell();
const alarm = new AlarmCell();

setTimeout(() => {
  camera.detectMotion(150, 220);
}, 2000);
